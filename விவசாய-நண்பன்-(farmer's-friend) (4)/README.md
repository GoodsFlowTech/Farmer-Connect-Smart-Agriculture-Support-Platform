# FarmFlow – AI-Powered Smart Agriculture Platform

## Overview

FarmFlow is an intelligent agriculture platform designed to assist farmers in making informed decisions related to crop management, farming practices, and agricultural productivity. The platform leverages modern technologies to provide smart and accessible farming solutions.

## Features

* AI-powered farming assistance
* Crop recommendations
* Weather-based insights
* User-friendly interface
* Smart agricultural guidance
* Responsive web design

## Technologies Used

* HTML
* CSS
* JavaScript
* AI Integration

## Purpose

The goal of FarmFlow is to support farmers by providing digital tools that simplify agricultural decision-making and promote efficient farming practices.

## Future Enhancements

* Real-time weather integration
* Crop disease detection
* Market price prediction
* Multi-language support
* Mobile application support



## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
